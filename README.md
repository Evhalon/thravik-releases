# Thravik

Signed and notarized builds of **Thravik**, a native macOS browser.

## Download

Grab `Thravik-macOS.dmg` from the [latest release](https://github.com/Evhalon/thravik-releases/releases/latest),
open it and drag Thravik into Applications.

Thravik checks this repository for updates and installs new versions itself,
so you only need to download it once.

## Changelog

Every [release](https://github.com/Evhalon/thravik-releases/releases) lists the changes it ships.
